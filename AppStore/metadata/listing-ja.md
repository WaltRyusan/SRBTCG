## アプリ名（30字以内）

```
サモランガイド｜Wave指示を声で記録
```

現在18字。「サモラン」は略称として定着しており、検索語として強い。
「Wave」「記録」で何をするアプリかが分かる。

ゲーム名そのものは入れない。権利者の登録商標であり、
非公式アプリが名称に含めるとリジェクトの理由になりうる。

## サブタイトル（30字以内）

```
話すだけで文字に。実戦前に読み上げ
```

現在17字。アプリ名と語を重複させない。
「話す」「読み上げ」で、音声を使うアプリだと伝える。

## キーワード（100字以内・カンマ区切り・スペース不要）

```
バイト,コンテスト,シャケ,オカシラ,カンスト,編成,立ち回り,メモ,音声入力,読み上げ,多言語,野良,味方,共有
```

アプリ名・サブタイトルで使った語は入れない。

## プロモーションテキスト（170字以内・審査不要で随時変更可）

```
Wave ごとの指示を声で話すだけ。文字に変換して記録し、実戦前に音声で読み上げます。
日本語・英語・韓国語・中国語に対応。海外の味方と組むときにも使えます。
```

## スクリーンショットのキャプション

**4枚構成。** 一覧で最初に見えるのは1〜3枚目なので、そこに主要な訴求を置く。

| 順 | 1行目 | 2行目 | アクセント色 |
|----|-------|-------|------------|
| 1 | Wave ごとの指示を | 話すだけで記録 | #F5A623 |
| 2 | 実戦前に読み上げ | 目を離さずに確認 | #34D399 |
| 3 | 4言語に対応 | 日本語・英語・韓国語・中国語 | #60A5FA |
| 4 | 記録は端末の中だけ | 声も文字も外へ送らない | #C084FC |

`app-support/tools/compose.swift` で合成する。

```bash
swift tools/compose.swift --in raw/01.png --out final/01.png \
  --title "Wave ごとの指示を" --sub "話すだけで記録" \
  --accent "#F5A623" --bg "#2A1F14,#15100A"
```

**背景色はアプリごとに変える。** 既定のままだと5本とも同じ暗い紫になり、
並べたときに同じ人が作ったものだと分かってしまう。

### App のプライバシー情報（栄養ラベル）

AdMob を使うため、以下を申告する。5本とも同じ。

| データ種別 | 用途 | ユーザーに紐づくか |
|-----------|------|-----------------|
| 識別子（広告識別子） | サードパーティ広告 | はい |
| 使用状況データ（製品操作） | 分析 | いいえ |
| 診断（クラッシュ、パフォーマンス） | アプリの機能 | いいえ |

**マイクで取得した音声は申告不要。** 端末内で文字に変換するだけで、
録音データを保存も送信もしていないため。
申告画面では「データを収集していません」を選べるが、
AdMob のぶんがあるので上記3種を申告する。

### 年齢制限レーティング

**4+**。暴力・性的表現・ギャンブル・ユーザー生成コンテンツのいずれも無い。

記録した文字は端末内にのみ保存され、他の利用者へ共有されない。
そのため「ユーザー生成コンテンツ」には当たらない。

## 注意点

配信地域は日本のみから始める。
欧州を含む地域へ広げるときは UMP（同意管理）の実装が必須になる。

多言語対応しているが、**v1 の配信地域は日本のみ**。
アプリ内で言語を切り替えられることと、配信地域は別の話。
