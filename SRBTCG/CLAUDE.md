# Claude コーディング指示書

このファイルは Claude Code でのコーディング作業における指示をまとめたものです。

## 基本ルール
- 日本語で回答すること
- コード内の説明コメントは日本語で記載すること

## 修正前
- 推測での回答はNG。コードなど根拠・エビデンスをもとに修正案を提案すること
- 仕様など不明点や懸念点があれば、修正前にこちらに確認すること
- **不明確な点はすべて確認してから実装すること（勝手に仕様を決めない）**
- **指示以外の勝手な実装は絶対に行わない（テキスト追加、UI変更、機能追加等）**
- 既存のコードパターンを確認し、プロジェクトの実装方針に従うこと
- 修正方針に複数パターンがあれば、各パターンのメリット・デメリットを併せて全て提示すること
- 既存のUIは勝手に変更せず、必要な場合は確認を取ること
- **技術的な提案をする際は、必ずデメリット・危険性・副作用を事前に調査・分析して明示すること**
  - 同期処理への変更：メインスレッドブロッキング、UI応答性悪化、ANRのリスク
  - アーキテクチャ変更：既存コードへの影響範囲、テスト工数、バグ混入リスク  
  - ライブラリ導入：依存関係の増加、メンテナンス負荷、セキュリティリスク
  - パフォーマンス最適化：コードの複雑化、可読性低下、デバッグ困難性
  - 外部API変更：互換性破綻、エラーハンドリングの複雑化

## 修正中
- コード修正後は必ず構文チェック（`swiftc -parse`）を実行してエラーがないことを確認すること
- 可能な場合は `xcodebuild build` でビルド確認も行い、BUILD SUCCEEDED するまでエラー調査→修正→再ビルドのサイクルを回すこと
- ビルドエラーが発生した場合は、エラーを解決するまで以下を繰り返すこと：
  1. エラー内容を分析
  2. 修正実施
  3. 再ビルド確認
  4. エラーが残っていれば1に戻る
- **修正前のロジック・機能が正常に動作するか必ず確認すること（矢印表示、タップ反応等）**
- 変更内容は必ず差分を表示すること
- 修正後は必ず自己レビューを行うこと。以下の観点で確認する:
  - 修正対象と同じパターンが他の箇所にもないか（同一ファイル内・関連ファイル含む）
  - 修正に伴いMock JSONなど関連するテストデータの更新漏れがないか
  - 変更の影響範囲を網羅的に洗い出し、修正漏れがないことを確認すること
  - 共通コンポーネント（プロトコル、Extension、基底クラス）を変更した場合、全ての呼び出し元・準拠型への影響を確認すること
  - MVVMパターンの遵守（View は `output` 経由でデータを受け取り、`input` を直接参照しない）

## 修正完了後
- 変更内容の差分を表示すること
- 主要な変更点を簡潔にまとめること
- 最後に「Xcodeで実機にRunしてください」と伝えること

## プロジェクト固有の情報

### アプリケーション概要
- バイトチームコンテスト（サーモンラン）ガイドアプリ
- Wave管理とSTT（Speech to Text）機能を搭載
- 課金要素：STT+Export機能、広告非表示、プレミアムバンドル

### アーキテクチャ
- SwiftUI + iOS 17対応
- @Observable マクロを使用したViewModel
- MVVM アーキテクチャ

### 主要ファイル構成
- `SRBTCGApp.swift` - アプリケーションエントリポイント
- `Views/` - UI画面
  - `ContentView.swift` - メインコンテナ
  - `HomeView.swift` - タブ切り替えホーム画面
  - `MainView.swift` - リスト一覧画面
  - `WaveListView.swift` - Wave詳細画面
  - `PlaybackView.swift` - 再生画面
  - `SalmonRunGuideView.swift` - ガイド画面
  - `SettingsView.swift` - 設定画面
  - `LanguageSelectView.swift` - 言語選択画面
- `Models/` - データモデル
- `ViewModels/` - ビューモデル
- `Utils/` - ユーティリティ
  - `AppColors.swift` - カラーテーマ
  - `AppStrings.swift` - ローカライズ文字列
  - `DateUtil.swift` - 日付処理
  - `PurchaseManager.swift` - 課金管理
  - `AdManager.swift` - 広告管理
